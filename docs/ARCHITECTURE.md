# Архитектура (этап 1)

**Почему live-build, а не Cubic.** Cubic — ручной графический инструмент, результат
нельзя воспроизвести из Git. live-build собирает ISO одной командой из текстовых конфигов.

**Как устроен репозиторий**
- `auto/config` — параметры образа (дистрибутив noble, amd64, hybrid ISO, BIOS+UEFI).
- `config/package-lists/*.list.chroot` — списки пакетов. Добавил строку — пакет в образе.
- `config/includes.chroot_before_packages/` — файлы, применяемые ДО установки пакетов (включение i386 для wine32).
- `config/includes.chroot/` — файлы, копируемые в систему (конфиги, `/etc/skel`).
- `config/hooks/live/*.hook.chroot` — скрипты, выполняемые внутри образа при сборке.

**Известные ограничения**
- Bottles ставится через Flatpak; если в chroot установка не удалась, её доделает мастер первого запуска.
- Настройка Calamares (брендинг, модули, шаги) — этап 2; пока ставится пакет с настройками Ubuntu по умолчанию.
- Сборка пока не прогонялась мной на реальной машине: возможны правки по результатам первого `build.log`.
