# Установщик RadiantOS (этап 2)

Основа: Calamares. Конфиги лежат в `config/includes.chroot/etc/calamares/`.

## Страницы
1. Язык, 2. Часовой пояс (автоопределение по IP), 3. Раскладка,
4. Диск (авто / рядом с Windows / вручную, галочка шифрования LUKS),
5. Пользователь (+ автовход), 6. Режим установки, 7. Доп. ПО, 8. Итог.

## После установки (`/usr/lib/radiantos/post-install.sh`)
ufw включён, автообновления безопасности, раскладка Alt+Shift.

## Не сделано в этой версии
- Выбор рабочего стола (сейчас только Cinnamon)
- Выбор канала обновлений
- Wi-Fi прямо в установщике (в live-системе работает значок сети в панели)
- Автоподбор темы/панели «как в Windows» (этап 5)
- Timeshift установлен, первый снимок предложит мастер первого запуска (этап 4)

## Тестирование
Установку проверять в VirtualBox (с виртуальным диском). В QEMU без ускорения она займёт часы.
