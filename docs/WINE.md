# Wine в RadiantOS (этап 3)

- **Двойной клик по .exe / .bat / .msi** открывает `radiant-run` (Qt, исходники в
  `config/includes.chroot/usr/src/radiantos/radiant-run`). Если программа сразу упала,
  показываются последние строки вывода Wine.
- **«Запустить программу Windows»** есть в меню приложений (выбор файла без терминала).
- **Первый вход:** `radiant-wine-init` создаёт префикс, ставит Windows 10 и шрифты
  (corefonts). Один раз, в live-сессии не работает.
- **Ярлыки в меню:** создаёт сам Wine (winemenubuilder включён по умолчанию).
- **Версия Windows:** по умолчанию Windows 10; сменить: `winecfg`.
